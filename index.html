The 3-stage restoration pipeline

How Again reconciles running processes, browser tabs, and coordinates in under 600ms.

1. Win32 enumeration

Queries running process IDs, window handles, and active browser tab URLs via UI Automation in under 15 milliseconds.

Execution time: 15ms

2. Deduplication engine

Checks active processes. Reuses open browser windows to inject missing tabs and stages unlaunched apps from your manifest.

Zero redundant processes

3. Concurrent placement

Positions windows concurrently via SetWindowPlacement and launches staged apps without desktop flickering.

Execution time: < 600ms

Core architecture

Designed for precision desktop management with zero cloud dependencies.

Smart browser tab injection

Instead of spawning redundant browser windows, Again locates your running Chrome or Edge process and appends missing tabs into the existing window.

Closed app catalog

Configure offline tools like Docker, Spotify, or IDEs to boot automatically when a workspace is loaded.

Coordinate clamping

PerMonitorV2 checks clamp window bounds to active monitors, preventing windows from opening off-screen when displays disconnect.

100% offline local storage

Workspaces save as human-readable JSON in %LOCALAPPDATA%\Again\workspaces\. Zero telemetry, zero accounts.

  "name": "Sprint",
  "windows": [
