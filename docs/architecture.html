The 3-stage restoration pipeline

How Again restores running processes, browser tabs, and coordinates in under 600ms.

1. Enumeration & reconciliation
  • [1] EnumWindows walks top-level handles, filtering cloaked virtual desktop windows.
  • [2] ChromiumBrowserService inspects active tabs on running Chrome/Edge windows.
  • [3] Missing tabs are queued for attachment into existing instances.
2. Clamping & placement
  • [4] PerMonitorV2 checks clamp negative coordinates to active screen bounds.
  • [5] Closed programs configured in offline catalog launch automatically.
  • [6] SetWindowPlacement restores coordinates simultaneously in < 600ms.
